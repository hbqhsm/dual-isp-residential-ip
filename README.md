## 双ISP住宅IP、原生IP、住宅IP，三个词经常被混着用

原生 IP 说的是 IP 注册地和机房物理位置一致，洛杉矶机房的 IP 在 WHOIS 里国家是美国。它解决的是“地区对不对”，不解决“像不像真人”。

住宅 IP 再进一步：这个 IP 的归属 ASN 是 Comcast、AT&T、中华电信这类民用宽带运营商，而不是数据中心运营商。平台风控查的就是这一层，机房段容易被判定为非真人流量，家宽段在数据库里看起来和普通家庭用户一样。

双 ISP 是第三层：同一个 IP 在两个民用 ISP 名下都有注册记录。它的实际作用是备份，其中一个段被某平台批量标记时，另一个段还挂着。常见的组合是美国 Comcast + Charter、香港 iCable + HGC 这类。

这里有个高频误解要纠正：**双 ISP 不是给你两个 IP**。WePC 全系每台机器只配 1 个 IPv4，双 ISP 描述的是这个 IP 的注册属性。

还有一层要分清：双 ISP 是 IP 属性，9929 和 4837 是线路属性，两者可以自由组合。同一台机器可以同时是“双 ISP 住宅 IP + 4837 回程”，也可以是“双 ISP + 9929”，价格差的正是线路这一层。

## 真实成本：AUD$12.90 买到的是 1.5TB，不是无限流量

美国全系，包括 AUD$39.90 的高配定制机，流量都是 **1.5TB 双向**。加钱买到的是 CPU、内存和硬盘，流量不跟着涨，这一点在套餐表里不显眼，但对直播用户影响很大。

算一笔：200Mbps 持续满速大约 25MB/s，1.5TB 折合约 157 万 MB，不间断跑满大约 17 个半小时就用完。当然实际使用不会一直满速，按直播 6Mbps 码率算，一小时约 2.7GB，一天播四小时约 11GB，1.5TB 能撑四个多月。但如果你同时做多账号上传素材、跑自动剪辑回传，流量消耗速度会完全不一样。

超量之后是限速到 3Mbps，不是停机。3Mbps 大概 375KB/s，发文字、刷后台够用，推流就别想了。买之前按自己的日流量乘一下，比看带宽数字有用。

## 下单前确认四件事

**当前分配的 IP 段属于哪两家运营商。** 美国产品组抬头写“全场双isp ip”，但单条描述标注不一致。工单问一句，比买完发现段不对再折腾省事。

**退款怎么算。** 官网建站类产品页标注了 30 天退款保证，双 ISP 产品页没有写退款条款。下单前问清楚是原路退回还是退到账户余额，两者的差别在你决定不续费时才显现。

**超流量限速的具体数值。** 美国产品组写 3Mbps，香港产品组写 5Mbps，不同产品线不一样，别按印象套。

**协议限制。** 美国产品组页面顶部明确写着严禁使用 Shadowsocks 协议，要求按官网教程搭建。这一条写在最上面，但很多人是买完才看到，然后发现自己的用法不合规。如果你本来就打算用这个协议，先想清楚替代方案。
